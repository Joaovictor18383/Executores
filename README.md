## ✨ Sobre

Este repositório mantém os arquivos usados pelo **SKY LAND**, incluindo o carregador e o script principal atualizado pelo GitHub.

O objetivo é deixar o sistema simples: o usuário abre o loader e ele busca automaticamente a versão mais recente do script publicado aqui.

## 📦 Arquivos principais

| Arquivo | Função |
|---|---|
| `GITHUB_SCRIPT.txt` | Script principal do SKY LAND |
| `Madium_Manager_Loader.bat` | Loader que busca e executa a versão mais recente |
| `README.md` | Documentação do projeto |

## ⚡ Como funciona

1. O loader inicia no Windows.
2. Ele consulta a versão publicada no branch `main`.
3. Baixa o `GITHUB_SCRIPT.txt` mais recente.
4. Valida o arquivo recebido.
5. Executa a versão atualizada do SKY LAND.

Dessa forma, as atualizações podem ser feitas diretamente no script central sem precisar redistribuir o loader a cada mudança.

## 🎮 Opções do SKY LAND

O menu atualmente reúne ferramentas para:

- **Potassium**
- **Madium**
- **Real**
- **Fishstrap**
- **Roblox Account Manager**
- **MultiBloxy**

## 🔄 Atualizações

As novas versões ficam centralizadas neste repositório. Para publicar uma atualização do menu, basta atualizar o arquivo `GITHUB_SCRIPT.txt` no branch `main`.

## 🔐 Segurança

O loader executa código publicado neste repositório. Antes de executar, confira o conteúdo e mantenha sua conta do GitHub protegida.

> Nunca publique senhas, cookies, tokens, chaves de API ou outras credenciais no repositório.
